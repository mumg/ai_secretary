Удалённое подключение

Выберите способ подключения. Приложение распознает его после сканирования QR-кода.

Телефон подключается к публичному HTTPS-адресу вашего сервера.

Прямое подключение недоступно в локальном режиме. Используйте шлюз или настройте публичный HTTPS при установке сервера.

QR-код содержит секретный ключ доступа. Не отправляйте его другим людям и не сохраняйте снимок экрана.

В приложении откройте настройки подключения → «Сканировать QR-код». Код автоматически скроется через 2 минуты. Это не отзывает выданный ключ.

Регистрация сервера

UID создаётся автоматически. Для регистрации достаточно адреса шлюза.

Надёжность и защита подключения

Сервер автоматически восстанавливает соединение со шлюзом после обрыва связи. Для подключения не нужны публичный IP-адрес и открытые входящие порты.

Трафик между устройством и вашим сервером защищён сквозным шифрованием. Шлюз передаёт зашифрованные данные и не имеет доступа к содержимому запросов и ответов. Ключи шифрования остаются на устройстве и вашем сервере.

Перерегистрация создаст новый UID и новые сертификаты. После неё подключите мобильные устройства заново по новому QR-коду.

QR-код содержит ключи доступа. Показывайте его только своим устройствам.

В Android выберите «Сканировать QR-код». Код скроется через 2 минуты; это не отзывает доступ.

Правила разбора ссылок на источник

По одному регулярному выражению на строку. Идентификатор встречи извлекается из группы (?P<meeting_id>...). Тип и идентификатор источника берутся из этой формы. Применяется первое совпавшее правило.

Проверка использует введённые правила без сохранения. Чтобы применить их, сохраните источник.

Установить расширение «AI Секретарь» для Chrome/Edge

Скачайте расширение и распакуйте архив. На странице chrome://extensions (или edge://extensions) включите режим разработчика и выберите «Загрузить распакованное расширение».

Нажмите значок расширения на этой странице админки. Повторяйте это после её перезагрузки. Браузер покажет панель отладки окна SSO — она нужна для получения результата входа.

Расширение «AI Секретарь» не обнаружено на этой странице. Установите его по инструкции выше или нажмите его значок, если оно уже установлено.

Можно ввести access token вручную. Он действует только 84 часа с момента выдачи, затем потребуется замена.

Токены сохраняются зашифрованно на сервере. Если вход отменён, новый источник останется выключенным.
