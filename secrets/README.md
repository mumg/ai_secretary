# Локальные секреты

Содержимое этой папки не попадает в Git. Перед запуском положите сюда:

- `postgres_password` — пароль PostgreSQL одной строкой;
- `app_master_key` — случайный ключ шифрования паролей адаптеров и Firebase JSON;

Пароли источников и Firebase service account вводятся через веб-панель и сохраняются
в PostgreSQL в зашифрованном виде. Ключ `app_master_key` нельзя менять без повторного
ввода этих секретов; его следует включить в защищённую резервную копию.

Для локальной проверки тестовые сертификаты можно создать командой:

```bash
docker compose run --rm cert-init
```

Сгенерированный клиентский PKCS#12 и тестовые TLS-материалы находятся в Docker
volume `tls_certs`; это только режим разработки. Для публичной установки заранее
поместите в этот volume отдельную клиентскую CA и публично доверенный серверный
сертификат либо замените volume на read-only mount вашего хранилища сертификатов.

Для публичного домена сертификат Let's Encrypt и приватный ключ находятся в
`letsencrypt/live/<public-host>/`. Переносите весь каталог `letsencrypt`, не только
файлы из `live`, поскольку они являются символическими ссылками на `archive`.
