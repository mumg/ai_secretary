# Регрессионная проверка анализа писем

Инструмент работает только с файлами в `regression/input/`. Он не читает базу,
настройки или состояние задач установленного приложения. Положите выгруженные
письма в `input/*.json`; примеры формата находятся в `examples/`. Для анализа
нужны `id`, `subject` (может быть пустой строкой), `direction`, `author`, `body`
и `user_identity` с массивами `names` и `addresses`. Контекст переписки,
участников и руководителей можно сохранить в том же JSON. Поля состояния задач
и поручений при анализе не используются.

Настройки модели хранятся отдельно в `regression/config.json`. Скопируйте
`config.example.json` и укажите адрес и модель. Для OpenAI-совместимой модели
передайте токен через `REGRESSION_API_KEY` или `--api-key-file`. Локальный
`config.json`, входные письма и результаты исключены из Git.

```sh
python3 regression/run.py
```

Откройте `http://127.0.0.1:8765/`. Для пакетного прогона используйте
`python3 regression/run.py --once`; один файл запускается с
`--once --case <имя-файла-без-json>`. Каждый запуск создаёт отдельный JSON в
`regression/results/`. Интерфейс показывает предложенные моделью задачи и
поручения, цитаты из письма и сырой ответ LLM. Он не назначает им статусы
приложения и не записывает ничего в его базу.

Оцените ответ как верный или неверный. При несогласии укажите причину и
ожидаемые названия задач и поручений по одному на строку; пустое поле означает,
что таких предложений быть не должно. При повторном прогоне результат
сравнивается с последней оценкой того же входного файла. Расхождения
подсвечиваются красным, совпадения можно скрыть. Фильтры помогают найти
письма с задачами или поручениями, без вашей оценки и ещё не обработанные
моделью из `config.json`.

Промпты и JSON-схемы лежат в `regression/llm_contracts.json`. Это локальный
снимок контракта для воспроизводимых тестов; изменения серверного кода не
меняют результаты регрессии автоматически. Ранее сохранённые прогоны можно
просматривать, но оценки, сделанные до перехода на чистые предложения модели,
нужно подтвердить заново.

Проверка инструмента:

```sh
python3 -m unittest discover -s regression -p 'test_*.py'
```
