# AI Секретарь — расширение Chrome/Edge

Исходники и иконки находятся в `src/`. Для разработки загрузите эту папку через
«Загрузить распакованное расширение» на странице `chrome://extensions` или
`edge://extensions`. После изменения файлов нажмите ↻ у расширения.

Из корня проекта соберите ZIP без дополнительных зависимостей:

```bash
python3 browser-extension/build.py
```

Архив для установки: `dist/ai-secretary-extension.zip`.
Сборка также помещает копию в `backend/src/improver/web/downloads/` для включения
в Python-пакет. Обе копии — генерируемые файлы, исключённые из Git.
В архив попадают только файлы расширения; порядок и даты записей фиксированы.

Перед локальным запуском или сборкой Python-пакета backend выполните команду выше.
Docker Compose собирает расширение автоматически при сборке backend.
Для отдельной сборки Docker используйте корень репозитория как контекст:

```bash
docker build -f backend/Dockerfile -t improver-backend:local .
```

Админка отдаёт этот архив по `/api/v1/admin/mts-link/extension.zip`.
После скачивания распакуйте его в постоянную папку и загрузите расширение из неё.
Для входа откройте `/admin`, нажмите значок расширения и выберите «Войти через SSO».
Полная инструкция для пользователя включена в архив как `README.txt`.
