AI Секретарь (Chrome/Edge 118+)

1. Распакуйте архив в постоянную папку.
2. Откройте chrome://extensions (Edge: edge://extensions), включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение», выберите эту папку.
4. Откройте /admin вашего Improver и нажмите значок расширения в панели браузера.
5. В источнике МТС Линк нажмите «Войти через SSO», введите рабочий email и выберите организацию.
6. Выполните корпоративный вход в открывшемся окне. Оно закроется после получения кода; админка сохранит токены на сервере.

После перезагрузки админки снова нажмите значок расширения. Оно не получает постоянного доступа ко всем сайтам.
Разрешение «отладка» нужно для остановки HTTP-редиректа mtslink://mobile/login до открытия мобильного/десктопного клиента.
Chrome показывает информационную панель отладки. Не отключайте её во время входа.
Расширение обрабатывает только отдельную вкладку SSO, которую создало само. Пароль не считывает, access/refresh токены не получает.
Пользовательский код SSO передаётся только вкладке админки, запустившей вход. Время ожидания — 15 минут.
Поддерживается облачный gateway https://gw.mts-link.ru и SAML/OAuth с HTTP-редиректом на mtslink://mobile/login.
Корпоративная политика браузера может запрещать установку расширений или API debugger; в этом случае требуется разрешение администратора браузера.
